## 天津津铁 STM32

两篇候选稿已写好，见[本地审阅记录](../experiments/tianjin-notes-2026-09-07/README.md)。目前等待用户审阅，旧五篇继续暂挂；以下保留选题依据。

**优先：16 个标定点能做什么，为什么还不算反馈控制？**

- 已有材料：ADC 从 1600 降到 480、PWM 0 到 1000 的表格，插值函数和主循环摘录。
- 可独立研究：画出目标、查表、PWM、实际 ADC 的数据流，推算插值与量化误差，再改变环境光，观察原映射何时失效。先说明完成的前馈行为，再讨论反馈需要增加什么。
- 需要补齐：重复测量、条件记录与误差评估；未来加反馈时另记新版本。采点、集成 demo 和实习评价保留在主页。

**备选：软件 I²C 能用，是否足以认定硬件 I²C 有故障？** 建立接线、电平、上拉、时序、外设状态和芯片勘误的排查顺序。旧项目没有 BUSY 和波形记录，无法追认根因；可以对现有板重新设计实验，但不能补造当年现场。

## 卷云相变散热器

**优先：慢传感器读取怎样与 EEV 步进共用主循环？**

- 已有材料：1、10、100、500、2000 ms 分档、EEV 增量回零、DHT 避让、通信等待与重试的状态拆分。
- 可独立研究：列出每段占用 CPU 的时间和可让出执行的位置，检查 flag 合并、迟到任务和异常路径，再设计执行时间及抖动测量。
- 需要补齐：当前源码核对和真实时间记录。使用经审核的最小片段或伪代码，不能发布完整产品固件；板卡设计、首次连通和交付喜悦仍留在主页。

**备选：参数保存到一半突然掉电，下次启动应读哪个值？** 先核对已有保存实现，再研究有效标记、版本、校验、写入顺序和恢复策略。Flash 日志或双区方案都是待选设计，不是已确认的现有功能；断电测试需另做并记录，不能虚构过去发生过参数损坏。

**已有文章继续承担：自动制冷如何让安全条件先于温度目标。** `juanyun-acunit-automatic-control` 已有独立控制问题，本轮保留公开。后续优先完善它的独有分析，不再写一篇同样的模式与安全概览。

## 无感 FOC

**优先：估计速度接近了，为什么还是不能接管？**

- 已有材料：30、45、60 Hz 开环测试点、RAM trace、EKF 修正、速度接近外加频率但接管失败。
- 可独立研究：区分速度与角度，把角度偏差、观测状态和切换前后参考连续性放到同一时间轴；先离线检查轨迹，再选择能够区分假设的台架实验。
- 需要补齐：具体 trace、单位和参考来源。没有编码器角度真值时，应说明能比较与不能比较的量；不把速度曲线或较安静的声音当作闭环成功。制造、SMT 与压缩机初次运行的过程留给主页。

**备选：电流采样放在 PWM 的哪个时刻才有意义？** 对照现有采样拓扑、放大器与 ADC 触发配置，研究开关边沿、可采样窗口和计算延迟。先从公开图纸确认信号路径，未测的波形、偏移与带宽留作实验问题，不把静态连线一致称为动态性能已经合格。

## Claude Chime 电源板

**优先：电池输出掉下去，怎样区分几种可能原因？**

- 已有材料：带保护电池输出从 4.03 V 降至 1.49 到 1.57 V、测阻、3.8 V / 50 mA 电源检查、外部电源介入后能再启动，以及缺失的连接电流波形。
- 可独立研究：围绕测量节点、仪表带宽、保护状态和实验顺序建立假设与区分条件，说明每一次测量能够排除什么、仍不能判断什么。
- 写作限制：不要再复述主页已经完整叙述的排查过程，也不重复双路升压选型、充电架构和交付。以后若不能提供新的测量方法、原理分析或区分性实验，就继续暂挂旧笔记；不能把电池包输出写成电芯电压，不能宣称已有浪涌波形或确定的保护触发状态。

**备选：带开关的 ADC 分压器何时才能读数？** 从已确认的分压与控制接口研究静态功耗、建立时间、ADC 采样要求和误差来源，先核对 ESP32 的实际采样设置。Alvin 没有编写客户固件，未来推导或实验不能变成客户软件已采用的方案。
