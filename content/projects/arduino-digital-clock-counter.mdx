## Two Digits Turn One Count Into Two Decoder Paths / 两位显示把一个计数值拆给两条译码链路

Group A17 completed this MEC104 breadboard project. The bench photograph shows an Arduino Nano beside two decoder ICs, two seven-segment displays, segment resistors, and two self-locking buttons. That physical topology answers the two-digit part of the brief: each display needs its own four-bit BCD route into an SN54LS47 decoder.

这是 MEC104 A17 小组完成的面包板项目。现场照片里，Arduino Nano 旁边排着两颗译码芯片、两位七段数码管、各段限流电阻和两个自锁按键。两位显示因此变成了很具体的拓扑：每位数码管各有一组四位 BCD 信号，分别送入一颗 SN54LS47。

![Breadboard digital-clock counter prototype / 面包板上的两位数码管计数器原型](/uploads/projects/arduino-digital-clock-counter/breadboard-counter-photo.jpg)

The course requirement and the A17 report do not describe the count in quite the same way. The slides require the counter to return to `00` whenever it reaches the group number. The report instead records an initial `16 -> 17 -> 00` sequence, then says the value continues toward 99 when neither switch is operated. Without the complete final program, it is not possible to tell whether that second sentence describes a startup sequence or a recurring rollover rule.

课程要求与 A17 报告对计数过程的描述并不完全一致。课件要求计数每次到达组号时回到 `00`；报告则写下首次 `16 -> 17 -> 00`，随后又说不操作开关时继续向 99 计数。缺少完整最终程序，无法判断后一句描述的是启动阶段，还是反复执行的归零规则。

## Modulo and Integer Division Split One Count Across Two BCD Paths / 取余与整数除法把一个计数值拆给两条 BCD 支路

The report maps `unitInputs[4]` to D9-D12 and `tensInputs[4]` to D5-D8. `unitNum = Num % 10` selects the units digit; `tensNum = (Num / 10) % 10` selects the tens digit. Each result indexes a BCD row and writes four bits to its own decoder. The report illustration uses an Arduino Uno, while the photographed bench build uses a Nano; the diagram records the branch layout rather than the exact controller board.

报告把 `unitInputs[4]` 映射到 D9-D12，把 `tensInputs[4]` 映射到 D5-D8。`unitNum = Num % 10` 取个位，`tensNum = (Num / 10) % 10` 取十位；两个结果各自索引一行 BCD，再把四个 bit 写给对应译码器。报告接线图画的是 Arduino Uno，现场照片用的是 Nano，因此这张图记录的是双支路布局，不是控制板型号完全一致的实物复刻。

## D2 and D3 Leave the Pressed Level Unresolved / D2 与 D3 留下未决的按下电平

The report assigns the reset and pause inputs to D2 and D3, but its polarity description is inconsistent. One paragraph calls a pressed switch high; the code excerpt checks switch 1 against `HIGH` and switch 2 against `LOW`; the closing paragraph describes a 10k-ohm pull-up that makes the input low when pressed. The `switch1Pressed` and `switch2Pressed` flags record software state, but they cannot resolve the wiring convention by themselves.

报告把复位和暂停输入分配到 D2、D3，但对有效电平的描述并不一致：一段正文把按下写成高电平，代码截图分别用 `HIGH` 判断 switch 1、用 `LOW` 判断 switch 2，末段又写 10k 欧姆上拉、按下时为低电平。`switch1Pressed` 和 `switch2Pressed` 标志位记录的是软件状态，单靠变量名无法反推出接线约定。

![Switch logic code from the homework report / 作业报告里的开关逻辑代码](/uploads/projects/arduino-digital-clock-counter/report-switch-logic-code.png)

Because the complete final source is missing, the exact pressed level for each input remains unresolved. The report still records the intended reset/pause roles and the work around a six-pin self-locking switch, but it cannot support a cleaner electrical story than the one written there.

由于缺少完整最终源码，两路输入各自采用什么按下电平仍然无法确定。报告能够说明复位/暂停的角色，也记录了六脚自锁按键带来的接线问题，但不能据此整理出一套比原文更整齐的电气结论。

## The Bench Video Shows the Display Changing / 现场视频拍到了两位显示持续变化

The [17-second bench video](/uploads/projects/arduino-digital-clock-counter/demo.mp4) follows the Nano build while the two illuminated digits change. That is the clearest visible result left by the project. No pause or reset action appears in the clip, so those functions remain described by the [A17 report](/uploads/projects/arduino-digital-clock-counter/digital-clock-homework-report.pdf) rather than demonstrated on camera.

这段 [17 秒现场视频](/uploads/projects/arduino-digital-clock-counter/demo.mp4) 跟着 Nano 面包板拍下了持续变化的两位发光数字，这是项目留下的最直接运行画面。视频里没有暂停或复位操作，因此这两项功能仍停留在 [A17 报告](/uploads/projects/arduino-digital-clock-counter/digital-clock-homework-report.pdf) 的描述中，没有得到镜头验证。

The two archived `.ino` files are the handout's one-digit BCD demo and D7/D6 Serial input test, not the final two-digit program. Together, the files leave a practical snapshot rather than a complete source tree: the Nano breadboard drives two changing displays, the report records the pin map, and pause/reset cannot be fully reconstructed from the remaining code.

两份存档 `.ino` 只是课件的一位 BCD 示例和 D7/D6 串口输入测试，并非最终两位程序。它们留下的是一张实用快照，而不是完整源码树：Nano 面包板驱动着两位变化的显示，报告记下了引脚映射，暂停/复位却无法由剩余代码完整复原。
