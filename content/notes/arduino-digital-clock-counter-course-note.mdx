## Four BCD Bits Choose One Visible Digit / 四个 BCD bit 选择一位可见数字

The MEC104 block diagram reduces the system to Arduino, decoder, and display, then notes that resistors and switches have been left out. That simplification is useful once each arrow is read as an interface. Arduino supplies four BCD bits on A-D; the 7447-style decoder converts them into a-g segment outputs; the display turns that pattern into one digit.

MEC104 框图把系统压成 Arduino、译码器和显示三段，下面也注明电阻、开关都没画全。把每条箭头当成接口来读，这种简化才真正有用：Arduino 在 A-D 上给出四位 BCD，7447 一类译码器把它转换成 a-g 段输出，数码管再把这组段码变成一位数字。

![Course system structure / 课程中的系统结构拆分](/uploads/projects/arduino-digital-clock-counter/course-system-structure.png)

The decoder slide fills in the electrical conditions around that interface: 330-ohm segment resistors, the IC orientation mark, Vcc on pin 16, and GND on pin 8. A correct BCD row is only half the job; power, orientation, and current limiting still decide whether the digit appears.

译码器页面继续补上接口周围的电气条件：330 欧姆段限流、芯片方向标记、16 脚 Vcc 和 8 脚 GND。写对一行 BCD 只完成了一半，供电、方向和限流仍然决定数字能不能亮出来。

![BCD decoder notes / BCD 到七段译码器说明](/uploads/projects/arduino-digital-clock-counter/bcd-decoder-notes.png)

## Two Digits Duplicate the Interface, Not the Count / 两位显示复制的是接口，不是计数状态

The handout's one-digit sketch makes the interface easy to see: D9-D12 stand in for A-D, one row of the `BCD` table is written at a time, and the value advances once per second. Moving to two digits does not require two independent counters. It requires the same counter state to be separated into two decimal digits, then sent through two copies of the four-bit interface.

课件的一位 sketch 很适合观察这层接口：D9-D12 对应 A-D，每次写入 `BCD` 表的一行，数值每秒推进一次。扩展成两位显示时，不需要再造一个独立计数器；同一个计数状态先拆成两个十进制数字，再分别走过两份四位接口。

`Num % 10` extracts the units digit, while `(Num / 10) % 10` uses integer division before extracting the tens digit. Each result selects its own BCD row. This is display routing, separate from whatever rule increments, pauses, or resets `Num`.

`Num % 10` 取出个位，`(Num / 10) % 10` 则先做整数除法，再取出十位；两个结果各自选择一行 BCD。这是在给显示分路，与 `Num` 如何递增、暂停或复位是两件事。

## A `...Pressed` Flag Cannot Define the Voltage / `...Pressed` 标志位决定不了电压

The switch slide starts one layer below the variable name. A pull-up or pull-down keeps the pin away from a floating state; only then does `digitalRead()` return a stable level. The D7/D6 demo prints two raw readings through Serial, which is enough to observe the inputs before attaching pause or reset semantics.

按键页面从变量名下面那一层讲起：上拉或下拉先把引脚从悬空状态里拉出来，`digitalRead()` 才能返回稳定电平。D7/D6 示例把两路原始读数打印到串口，先观察输入，再赋予暂停或复位含义。

![Button pull-up and pull-down notes / 按键上下拉说明](/uploads/projects/arduino-digital-clock-counter/button-pullup-notes.png)

The report excerpt checks `switch1Pressed` after a `HIGH` reading and `switch2Pressed` after a `LOW` reading; elsewhere, its prose also disagrees about the pressed level. A `...Pressed` flag describes the program's interpretation, not the voltage at the pin. Without the matching final wiring and full source, the polarity cannot be recovered from the identifier.

报告截图在读到 `HIGH` 后设置 `switch1Pressed`，却在读到 `LOW` 后设置 `switch2Pressed`；报告其他文字对按下电平也没有统一说法。`...Pressed` 标志位描述的是程序解释，不是引脚电压。缺少对应的最终接线和完整源码，不能从变量名反推极性。

## Independent Blocks Make Integration Observable / 独立功能块让集成过程可观察

The milestone slide orders timing, decoder, display, programming, and testing as separate blocks. The two demo sketches fit that order: one exercises a single BCD display route, and the other exposes two button levels through Serial. The handout explicitly says these are not the final program.

里程碑页面把计时、译码、显示、编程和测试列成独立功能块。两份 demo sketch 正好落在这个顺序里：一份检查单路 BCD 显示，另一份通过串口暴露两路按键电平。课件明确说明，它们不是最终程序。

![Milestone breakdown / 课程里程碑拆分](/uploads/projects/arduino-digital-clock-counter/milestone-breakdown.png)
![TinkerCAD one-digit demo / TinkerCAD 一位归零计数 demo](/uploads/projects/arduino-digital-clock-counter/tinkercad-one-digit-demo.png)

The TinkerCAD example sits even earlier in the sequence: an Uno and CD4511 drive one digit in a simulation that the slide labels unassessed and not identical to the lab project. Its role is to make one interface legible before integration, not to stand in for the two-digit circuit.

TinkerCAD 示例位于更早的阶段：Uno 和 CD4511 在仿真里驱动一位数码管，课件同时注明它不计入考核、也不等同于实验项目。它的作用是在集成前把一条接口讲清楚，而不是代替最终两位电路。

The resulting verification order is compact: establish one BCD display route, define and observe the button levels, duplicate the display interface, then integrate the counter state. If the voltage convention is still inconsistent, the next step is to recheck the circuit rather than let a flag name decide it.

由此得到的验证顺序很紧凑：先建立一条 BCD 显示链，确定并观察按键电平，再复制显示接口，最后集成计数状态。如果电平约定仍不一致，下一步应回到电路复查，而不是让标志位名称替硬件下结论。
