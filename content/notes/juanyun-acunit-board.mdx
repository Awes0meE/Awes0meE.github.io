## Three Board Names Anchor the Interface Set / 三个板名把接口收在一起

The V2.1 image reads more like a Chinese interface mind map. `24V_COM_BUS / MAX 10A` and `+12V_MAIN / MAX 2A` run from the power board toward the main board. Around the main-board node are labels for an STM32F103C8T6, two 12 V four-wire PWM fans, a five-pin electronic expansion valve, five NTC channels, a three-pin linear pressure-sensor input, DHT11, compressor Modbus UART, ESP-01S Wi-Fi, HC-05 Bluetooth, and an ST-Link SWD port. The interaction branch reaches page buttons and an EC11 encoder with a push switch; a separate branch lists an I2C 0.96-inch OLED.

V2.1 图更像一张中文接口思维图。`24V_COM_BUS / MAX 10A` 与 `+12V_MAIN / MAX 2A` 从分电板指向主控板；主控板节点周围依次标出 STM32F103C8T6、两把 12 V 四线 PWM 风扇、五针电子膨胀阀、五路 NTC、三针线性压力传感器输入、DHT11、压缩机 Modbus UART、ESP-01S Wi-Fi、HC-05 蓝牙与 ST-Link SWD。交互支路连到翻页按键和带按键的 EC11 编码器，另一支则标出 I2C 的 0.96 英寸 OLED。

![ACUnit V2.1 interface map / ACUnit V2.1 接口思维图](/uploads/projects/juanyun-tech/acunit-v21-system-block.png)

The map identifies which board each interface is drawn around, but it leaves connector part numbers, trace widths, assembly state, and test results open. The separate [diagram revision archive](/notes/juanyun-acunit-hardware-revision-archive) follows how this branch map differs from the routed V2.0 drawing.

这张图能定位每个接口围绕哪块板展开，却没有连接器料号、走线宽度、装配状态或测试结果。另一篇[框图版本归档](/notes/juanyun-acunit-hardware-revision-archive)再单独追踪这棵分支图与 V2.0 连线图在表达方式上的差异。

## The Main Board Is Dense Around Its Edges / 主控板的密度集中在板边

On the main-board front render, the STM32 package sits near the centre-right. Headers and connectors occupy most edges; visible labels include fan, NTC, OLED, DHT, interaction-board, Wi-Fi, and reset positions. The back render is much quieter, showing mounting holes, through-hole pads, and routing rather than a second field of components.

主控板正面渲染里，STM32 封装位于中间偏右，排针与连接器几乎围住板边；能辨认的标签包括风扇、NTC、OLED、DHT、交互板、Wi-Fi 与复位。背面安静得多，主要是安装孔、通孔焊盘与走线，并没有再铺一层同样密集的器件。

## Power and Interaction Use Narrower Layouts / 分电与交互各自收窄了布局

The power-board front render visibly groups a DC jack, a blade fuse, an inductor marked `470`, conversion components, and a screw terminal marked `+12V / PGND`; wide copper is visible on the back. The interaction-board front shows an encoder and two push buttons. Its back header is labeled `A / B / G / EK / KP / KN`, making the user-input signals easier to inventory than they are in the front view.

分电板正面把 DC 插座、片式保险丝、标着 `470` 的电感、变换器件与 `+12V / PGND` 螺钉端子放在一起，背面则能看到较宽的铜箔。交互板正面是一只编码器和两个按键；背面排针标着 `A / B / G / EK / KP / KN`，用户输入信号反而在背面更容易点清。

## Parameter Screenshots Define Candidate Constraints / 参数截图给出候选约束

One product screenshot labels a Sanhua YCQB02H31 pressure sensor with 5 V supply, 0-20 bar range, 0.5-4.5 V output, and a two-metre lead. Another labels a 140 x 140 x 25 mm, 12 V, four-pin PWM fan and lists speed, airflow, pressure, current, and power figures. These values are useful when thinking about connector power, input range, and PWM/feedback pins, but the screenshots do not show that either item was selected, purchased, connected, or measured in this platform.

一张产品截图给三花 YCQB02H31 压力传感器标出 5 V 供电、0-20 bar 量程、0.5-4.5 V 输出和两米线长；另一张给 140 x 140 x 25 mm、12 V、四针 PWM 风扇列出转速、风量、风压、电流与功率。它们适合拿来考虑连接器供电、输入范围以及 PWM / 反馈引脚，却不能说明这两个器件已经被选型、采购、接入或实测。

![Pressure-sensor product screenshot / 压力传感器产品截图](/uploads/projects/juanyun-tech/acunit-v21-pressure-transmitter-params.jpg)
![PWM-fan product screenshot / PWM 风扇产品截图](/uploads/projects/juanyun-tech/acunit-v21-pwm-fan-params.jpg)

Taken together, the diagrams and renders answer a narrow but useful question: where the labeled power, sensing, actuator, communication, and user-interface connections appear. Electrical checks, physical clearances, startup behavior, and reliability still need records from a real board.

把这些图放在一起，能回答一个窄却有用的问题：标注过的电源、传感、执行器、通信与用户交互连接分别出现在哪里。电气检查、实物间隙、启动表现与可靠性，仍要等真实板卡记录来回答。
