# Ending Variety Regression

Manual editorial cases for the user's 2026-09-06 clarification. Test both
project homepages and notes, and Chinese and English. These are contextual
judgments, not zero-hit lexical tests. Historical Trials 01-11 remain frozen.

| Case | Material | Expected judgment |
| --- | --- | --- |
| Repeated literal opening | Several adjacent articles end with `现在再看……`. | Repair the repeated closing move from each article's content. |
| Synonym rotation | A batch ends with `回头看……`, `下一次再看到……`, and `如果重新做……`, each followed by the same generic lesson. | The different openings still repeat one template; repair the batch. |
| Apt occasional use | One packaging note ends with `下一次再看到开发机上能跑的结果，我大概不会那么快把它叫作 Release 了。`; nearby pages close in ways suited to their own subjects. | Allowed when the packaging problem supports it. Do not ban the sentence. |
| Concrete next work | A motor note proposes recording target rpm, measured rpm, PWM and battery voltage under load to investigate speed error. | A useful next investigation may close the note; it is not a claim that logging already happened. |
| English recurrence | Nearby endings rotate `Looking back`, `Returning to`, and `If I did this again` around the same closing move. | Review the recurring function, not only literal matches or the Chinese endings. |
| Direct closure | A display note ends with concrete ways to trace a missing segment or an incorrect digit. | Can close the investigation without an added look-back sentence or growth claim. |
| Real chronology and conditions | The body says the writer returned to inspect a window event, or explains what happens when a reset and a count update coincide. | Preserve relevant facts and conditions; the repetition rule is not a ban on return/future vocabulary. |
| Abrupt cut | An editor deletes the ending and leaves a disconnected measurement table. | Restore the connection needed to finish the account; avoiding a repeated frame does not mean omitting closure. |

Review the current batch and relevant recent pages together. Do not prescribe a
fixed number of permitted callbacks or force a different ending category onto
each article. Record the reviewed scope rather than claiming a corpus-wide pass
from a single isolated sentence.
